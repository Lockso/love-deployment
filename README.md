# ❤️ Love Deployment

> Deploying feelings to production. 🥹❤️

A tiny romantic web app designed to ask someone out in a fun, playful and slightly unfair way.

## ✨ Features

* 🐱 Cute floating cat mascot
* 💖 Soft pastel UI
* 🏃 Escaping "No" button
* 📅 Date selection
* 🍕 Activity selection
* ⏰ Time selection
* 📧 Email notification
* 🎉 Celebration ending
* 📱 Mobile-friendly design

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/love-deployment.git
```

Open `index.html` in your browser or deploy it to your favorite hosting provider.

## 🛠 Configuration

Update the email destination inside:

```text
ajax/sendEmail.php
```

```php
$to = "your@email.com";
```
